# Task Management System

## Features
- User Registration/Login
- JWT Authentication
- Role-Based Access
- CRUD Task Management
- MongoDB Database
- Protected Routes

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Vanilla JavaScript

## Installation
npm install
node server.js

## API Endpoints
POST /api/v1/auth/register
POST /api/v1/auth/login
GET /api/v1/tasks
POST /api/v1/tasks
PUT /api/v1/tasks/:id
DELETE /api/v1/tasks/:id
